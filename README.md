# Python Web Scraper

A clean and automated Web Scraper built using Python to extract structured data from websites and save it in CSV format.

## 🚀 Features
- Scrapes quotes and authors from web pages.
- Cleans special characters and smart quotes for standard encoding.
- Exports formatted data into a clean `quotes_output.csv` file using Pandas.

## 🛠️ Tech Stack
- **Python 3**
- **Requests** (HTTP requests)
- **BeautifulSoup4** (HTML Parsing)
- **Pandas** (Data Formatting & CSV export)
